# Dotfiles

This directory contains configurations files (dotfiles) for my personal system.

## Requirements

- [Homebrew](https://brew.sh/)
- Git `brew install git`
- Stow `brew install stow`

## Installation

Clone the repository
```
$ cd ~
$ git clone git@github.com:divsmith/.dotfiles.git
```

Use `stow` to create symlinks to the configs
```
$ cd .dotfiles
$ stow .
```
